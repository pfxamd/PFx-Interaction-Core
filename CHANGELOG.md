# Changelog

## [0.1.0] - 2026-10-08

- First standard GitHub Release with downloadable builds for all four packages and SHA-256 checksums.
- Completed cross-browser validation in Chromium, Firefox and WebKit.
- Reproducible workspace installs with pnpm lockfile and license notices in distributions.
- No npm registry publication. As a pre-1.0 project, APIs may evolve in future minor versions.


## [0.1.0-beta.2] - 2026-10-08

- Verified public GitHub release workflow with compiled package archives.
- Committed the pnpm workspace lockfile and enabled frozen installs in CI.
- Added Apache license and notice to each downloadable package.
- Expanded touch, pen and multipointer drag tests.
- Avoided retaining positions from inactive pointer-move events.
- Published artifacts with SHA-256 checksums.


## [0.1.0-beta.1] - 2026-10-08

First preview release of the headless interaction foundation.

- Independent core, DOM, React, and testing packages.
- Gesture recognizers, constraints, snapping, values, springs, and inertia.
- Safer DOM pointer-capture cleanup and expanded regression tests.
- Apache-2.0 licensing, developer examples, and validated prerelease workflow.

This prerelease does not promise stable APIs or npm package availability.
