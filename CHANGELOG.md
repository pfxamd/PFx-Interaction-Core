# Changelog

## [0.1.0-beta.1] - 2026-10-08

First preview release of the headless interaction foundation.

- Independent core, DOM, React, and testing packages.
- Gesture recognizers, constraints, snapping, values, springs, and inertia.
- Safer DOM pointer-capture cleanup and expanded regression tests.
- Apache-2.0 licensing, developer examples, and validated prerelease workflow.

This prerelease does not promise stable APIs or npm package availability.
