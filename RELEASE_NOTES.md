# PFx Interaction Core v0.1.0-beta.1

The first GitHub prerelease of the framework-independent interaction foundation.

- Four workspace packages: core, DOM, React bindings, and deterministic testing utilities.
- Gestures, pointer and keyboard input, constraints, values, spring and inertia helpers.
- Playground, documentation, and browser/unit regression tests.
- Apache-2.0 license.

**Experimental:** the APIs can change before v1.0.0, and these packages have not been published to npm.
